# Bundled RS example

RS.data.csv is the handbook dataset exported from rENA::RS.data, distributed
with the existing pyENA examples/rs example. This packaged copy is derived
from examples/rs/datasets/RS.data.csv; tests enforce byte-for-byte equality.
Update the example source and bundled copy together when changing the dataset.
The YAML reproduces examples/rs/example.py, including its two focus units.
